# Ingreso Urgente

`ingreso_urgente` — point-and-click adventure skeleton generated by
`tools/scaffolder`. Wires up every scene the engine ships so the new game
has a complete loop on day one: a title screen with `Nuevo juego` /
`Continuar` / `Recuperar partida` / `Opciones` / `Salir`, a manual-mode
intro cutscene, a starting room, and the settings + save/load pickers.

Open the placeholders, change the title art, edit the intro slides, write
your first room — the engine handles the wiring.

## Run

From the repo root:

```bash
cmake --build build -j"$(nproc)"
./build/games/ingreso_urgente/pac_ingreso_urgente
```

Headless smoke + screenshot:

```bash
./build/games/ingreso_urgente/pac_ingreso_urgente --frames 60 --shot out.png
```

The pak workflow (#109) works the same way — drop `resources.pak` next to
the binary, or pass `--pak path/to/resources.pak`.

## Layout

```
data/
├── game.yaml                      # manifest: scenes, resolution, settings
├── cast.yaml                      # one character: `player` -> blob_body
├── characters/blob/               # placeholder avatar (32x48 PNG + atlas + anim)
├── cutscenes/intro.yaml           # manual-mode intro slides (Cutscene)
├── rooms/
│   ├── lab.yaml                   # starting room (navy fill, no layers yet)
│   └── lab.lua                    # behaviour stub (hooks, hotspots)
├── scripts/game.lua               # global fallback verb handler
├── strings/es.yaml                # required ui/verbs/connectors/defaults
├── title/title_screen.png         # placeholder gradient title backdrop
└── fonts/DepartureMono-Regular.otf  # bundled (OFL)
```

## Tweak first

1. Replace `data/title/title_screen.png` with your real title art.
2. Edit `data/cutscenes/intro.yaml` — slides, durations, optional images.
3. Open `data/rooms/lab.yaml`: add background layers (`layers:` block),
   hotspots, regions, NPCs.
4. Implement hotspot verb handlers in `data/rooms/lab.lua`.
5. Swap the placeholder blob for your character: add a real spritesheet
   under `data/characters/<id>/` and update `data/cast.yaml`.
6. (Optional) Rename the starting room: rename `lab.yaml` / `lab.lua` and
   update `start_room:` in `data/game.yaml`.
