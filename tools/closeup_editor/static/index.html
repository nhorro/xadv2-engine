    How to

    • New hotspot → click points on the image; double-click to close (≥3 points), then name it.
    • Click a polygon (or list row) to select it.
    • Drag a vertex to move it.
    • Shift-click an edge to insert a vertex.
    • Right-click a vertex to delete it.
    • Esc cancels an in-progress polygon.
    • Save writes polygon geometry back to hotspots: or template slots: (other fields are kept; comments are not).
